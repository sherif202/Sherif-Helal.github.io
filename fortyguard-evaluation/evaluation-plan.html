      To agree before testing starts

      1. Timebox. 135 minutes against a 45 to 90 guide. Proposed trim to about 90: context to 10, dashboard to 20, API to 20, MCP to 15, synthesis to 20, and drop the optional PRD and wireframe unless time remains.
      2. Deadline. The email omitted it. Ask support in phase 0; if no answer, assume 3 working days.
      3. One goal per product. Dashboard: time to first insight. API: time to first successful call. MCP: answer correctness against the API.
      4. Test city set. One major US city for the core flow, plus "Springfield" for ambiguity and "Paris" for non-US handling.
      5. Validation ideas stay ideas. Clarity analytics and A/B tests are recommended, not run.
